# Quartiers stylés (v0.4)

Chaque quartier a un **profil** (`src/data/districtProfiles.ts`) : palette, types d’immeubles, hauteurs, places publiques.

| Type | Exemples | Architecture |
| --- | --- | --- |
| Centre commercial | Centre-ville, Kennedy, Nlongkak | Tours, bureaux vitrés, commerces RDC |
| Marché | Mokolo, Mfoundi, Mvog-Ada | Étals, tôles, boutiques basses |
| Premium | Bastos, Odza | Villas, clôtures, pelouses |
| Campus | Ngoa-Ekellé | Équipements, immeubles étudiants |
| Dense populaire | Biyem-Assi, Essos, Ekounou | Immeubles + boutiques |
| Familial | Mendong, Cité Verte, Ahala | Maisons, épiciers |
| Logistique | Mvan, Nsam | Entrepôts, stations |
| Institutionnel | Etoudi | Bâtiments publics, espaces verts |
| Périurbain | Simbock, Awaé, Emana | Lotissements plus bas |
| Aéroport | Nsimalen | Halls / entrepôts légers |

HUD : le tip sous le nom du quartier décrit le caractère (`blurb`).
